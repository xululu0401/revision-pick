# 改稿取舍台
纯文本逐行LCS差分，连续插入/删除聚合成块，用户对每块保留原稿或采用改稿。全决定后导出TXT合成稿、MD取舍记录和PNG摘要；JSON备份与浏览器手动保存恢复包含取舍选择。无外部API和文本上传。

每版最多200行、12000 Unicode码点，CRLF/CR统一LF，空格不忽略，末尾LF作为空行处理。空稿合法。重复行固定优先删除旧行，移动表现为增删，不做语义分析/事实审核。每块整体取舍，不保留富文本格式。PNG只列前8块和总计。

`node build.cjs` 生成独立index.html；`node --test tests/core.test.cjs` 跑测试；静态部署本目录即可。封面脚本使用现有sharp路径，可替换为本机安装路径。

虚构默认通知：3块变动，新增3行、删除2行、相同3行。选择原、新、新合成6行；所有文案数字由core结果生成。
